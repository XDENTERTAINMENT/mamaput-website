# Prompt Engineering Used

## Prompt For Header Section

Create a modern Nigerian food restaurant navigation bar.

Requirements:

- Logo at top left
- Search bar at top right
- Dark red color palette
- Navigation links:
  Products
  Services
  Customer Service
  Contact Us
- Sticky navigation
- Responsive layout

## Prompt For Hero Section

Create a two-column hero section.

Requirements:

- Left side:
  Large marketing text
  Call To Action button

- Right side:
  High-quality steaming Nigerian food image

- Height should occupy at least 30% of screen

- Modern restaurant landing page style
